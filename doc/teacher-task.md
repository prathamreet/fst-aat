Portfolio-Driven Assessment – Full Stack Technologies

Students are required to develop a Mini Full Stack Web Application as part of the Portfolio-Driven Assessment.

Suggested Project Topics:
Student Management System, Library Management System, Expense Tracker, To-Do App, Online Quiz System, Event Management System, Inventory Management System, Course Registration System, Placement Portal, etc.

Technologies that can be used:

* Frontend: HTML, CSS, JavaScript / React
* Backend: Node.js + Express.js
* Database:MongoDB
* API: REST API
* Version Control: Git & GitHub
* Deployment:Optional

The application should demonstrate Frontend + Backend + Database connectivity and include basic CRUD operations – Create, Read, Update and Delete.

Final Submission: Project source code + GitHub link + screenshots/output + short project report.

Submission Date: 1st October 2026

Students may select different project topics, but the application must clearly demonstrate Full Stack concepts.

Note:The final hard-copy submission template/format will be shared separately once confirmation is received from the Course Coordinator. Until then, start selecting your project topic and developing the application.

Complete the assessment and be ready for submission on or before 1st October 2026.
